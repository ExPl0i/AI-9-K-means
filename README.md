# Кластеризация методом k средних

Занятие курса «Искусственный интеллект» для 9 класса и первое занятие по обучению без учителя. Ученики пишут метод k средних (алгоритм Ллойда) на чистом Python, наблюдают, как он сходится и где застревает, реализуют повторные запуски и инициализацию k-means++, выбирают число кластеров методом «локтя» и проверяют, найдет ли метод три сорта вина, если скрыть от него правильные ответы.

## Теория (презентация)

1. **Задача кластеризации.** Обучение без учителя, когда правильных ответов нет. Постановка задачи, центры кластеров и инерция как мера качества.
2. **Алгоритм Ллойда.** Шаг назначения и шаг пересчета центров, разбор одного шага на пяти точках, доказательство того, что алгоритм всегда останавливается.
3. **Роль начальных центров.** Локальные минимумы, инициализация k-means++ с начальными центрами подальше друг от друга.
4. **Число кластеров и границы метода.** Метод «локтя» на примере объектов на парковке, влияние масштаба признаков на наборе Wine, ситуации, в которых метод ошибается, сокращение числа цветов изображения.
5. **Практика.** План из восьми заданий.

## Практическая работа

Сквозной пример: 280 точек лидара на парковке, по которым нужно определить число объектов.

| Задание | Что пишем | Главный результат |
|---|---|---|
| С1 | `dist2`, `closest_center`, `assign_clusters` | шаг назначения точек кластерам |
| С2 | `update_centers` | шаг пересчета центров |
| С3 | `inertia` | мера качества кластеризации |
| С4 | `kmeans` | алгоритм Ллойда на сцене из шести объектов |
| С5 | `random_init`, `kmeans_restarts` | локальные минимумы и повторные запуски |
| С6 | `kmeans_pp_init` | инициализация k-means++ |
| С7 | метод «локтя» | число кластеров |
| С8 | `contingency`, `purity` | кластеры на наборе Wine в сравнении с настоящими сортами, сверка с `KMeans` из scikit-learn |

Задания повышенной сложности: сокращение числа цветов изображения, кластеризация объектов на дороге для беспилотного автомобиля без разметки, метод k медиан, устойчивость выбранного числа кластеров, обучение по мини-пакетам.

**Правило работы:** внутри своих функций разрешены только списки, словари, циклы, модули `math` и `random`. Библиотека `scikit-learn` нужна только для загрузки набора Wine и для сверки в задании С8, `matplotlib` используется только в готовых ячейках с графиками.

## Данные

1. Синтетическая сцена парковки: точки лидара, принадлежащие нескольким объектам.
2. Набор Wine из scikit-learn: 178 вин трех сортов, 13 химических признаков (сорта скрываются от алгоритма и используются только для проверки).
3. Синтетический набор «две луны», на котором видны ограничения метода.
